# AI 阅读索引

> 本文档供 AI（主协调者/子 Agent）阅读，用于确定按需加载哪些文档。
> 人类开发者也可参考。

## 读取规则

1. **首次启动**：先读本文档，了解文档结构和加载规则。
2. **按需加载**：根据当前任务，从下方映射表找到对应文件，只读需要的文件。
3. **禁止全量加载**：除非用户明确要求，否则不一次性读取所有文档。

## 关键约束（所有 Agent 必须遵守）

- 数据默认不出本机；云端只接脱敏描述
- 写操作必须走权限网关（L2 confirm）
- 数据根：`AI_ASSISTANT_DATA` 环境变量优先；否则 debug 用 `{仓库目录}/data/`，release Windows 用 `%LOCALAPPDATA%\ai-assistant-data`，其他平台用 `$HOME/.local/share/ai-assistant/data`
- 本地/云端边界按 `roadmap/18-本地云端边界方案.md`（读/检索/工具永远本地，仅「生成」环节可按需上云兜底）；阶段 0-2 以本地推理为主，不直加载 GGUF
- 配置文件格式：JSON（缩进 2 空格）
- 知识文件格式：结构化 JSON
- 角色定义格式：YAML
- 前端：纯 HTML+CSS+JS（Tauri v1）
- 网络访问：常见文档站默认允许，其他首次询问（用户可配置）
- 主协调者（8B）常驻，子 Agent 按需唤醒
- 失败处理：按类型重试→检查原因→回滚→报告用户
- 并发写互斥：文件锁（`workspace/.locks/`，5 分钟超时）
- 写前备份：任何写操作先备份到 `backups/{批次}/`（见 21）
- 显存/并发调度：见 `design/27-性能优化.md`（3B 路由常驻 GPU、8B 主协调 offload、子 Agent 3B 并发 2）

# 08 - 记忆与知识

> 状态：已定稿 | 最后更新：2026-01-15 | 关联：02-架构设计.md、04-数据边界.md、07-主协调者.md、30-总结与路线图.md

## 一、概述

记忆与知识模块是 ai-assistant 的**长期信息管理层**，负责维护跨会话的用户偏好、角色专属上下文，以及可检索的外部知识库。该模块分为两个子系统：

- **记忆系统**：存储用户和角色的短期/长期上下文，支持角色切换时的隔离与复用
- **知识库系统**：存储结构化知识条目，支持手动/自动添加与多策略检索

**设计决策摘要**：
- 记忆分两层：独立（角色私有）+ 公共（所有角色可读不可改）
- 知识库分三层：`shared/`、`general/`、`{custom_role}/`
- 知识文件格式：结构化 JSON
- 检索策略：先关键词后向量（阶段 3+ 升级）
- 知识维护：混合模式（`manual` / `agent` / `hybrid`）
- 链接自主学习：抓取→总结→存入知识库，外网需询问且不能太频繁

### 2.1 分层架构
AI_ASSISTANT_DATA/
├── memory/

### 2.2 公共层（shared）

| 文件 | 内容 | 读写权限 |
|------|------|---------|
| `user_profile.json` | 用户名、语言偏好、硬件信息、常用路径 | 主协调者可写，角色只读 |
| `global_facts.json` | 项目列表、技术栈、常用命令、Git 配置 | 主协调者可写，角色只读 |
| `_access_log.jsonl` | 访问时间、角色、读取的键 | 追加写，角色不可读 |

**关键约束**：角色层**不可修改**公共层任何文件。如需更新，必须通过主协调者（7B）验证后写入。

### 2.3 独立层（{role}）

| 文件 | 内容 | 读写权限 |
|------|------|---------|
| `preferences.json` | 角色专属偏好（如代码风格、输出格式） | 当前角色可读写 |
| `history_summary.json` | 历史对话的摘要压缩版本 | 当前角色可读写 |

> 会话级上下文缓存放 `cache/role_contexts/{role}.json`（见 `07-主协调者.md` §5.4，决策 10），不入记忆目录。

**隔离保证**：角色 A 无法访问 `{role=B}/` 下的任何文件。路径遍历防护见 `04-数据边界.md`。

### 3.2 知识文件格式（结构化 JSON）

每个知识文件为一个 JSON 数组，包含多个知识条目：
json
[
{
"id": "kb_001",
"title": "Rust 异步运行时选择",
"content": "tokio 是 Rust 最成熟的异步运行时，支持多线程和单线程模式...",
"keywords": ["rust", "async", "tokio", "runtime"],
"source": "manual",
"created_at": "2026-01-15T10:00:00+08:00",
"updated_at": "2026-01-15T10:00:00+08:00",
"embedding": null,
"metadata": {
"category": "programming",
"confidence": 1.0,
"tags": ["rust", "async"]
}
}
]
纯文本
**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 唯一标识符，格式 `kb_{seq}` |
| `title` | string | 知识条目标题 |
| `content` | string | 知识正文（支持 Markdown） |
| `keywords` | string[] | 关键词列表（用于关键词检索） |
| `source` | enum | `manual` / `agent` / `hybrid` |
| `created_at` | datetime | 创建时间（ISO 8601） |
| `updated_at` | datetime | 更新时间 |
| `embedding` | float[] \| null | 向量嵌入（阶段 3+ 填充） |
| `metadata` | object | 扩展元数据 |

### 3.3 知识维护模式

| 模式 | 说明 | 示例 |
|------|------|------|
| `manual` | 用户手动添加 | 用户编辑 JSON 文件 |
| `agent` | AI 自动生成 | 对话中总结的知识点 |
| `hybrid` | 手动触发+AI 总结 | 用户给链接，AI 抓取并总结 |

## 四、与主协调者的交互

### 4.1 记忆注入

主协调者在任务拆解前，自动加载相关记忆：

1. 读取 `memory/shared/global_facts.json`（始终加载）
2. 读取角色缓存池 `cache/role_contexts/{role}.json`（决策 10）
3. 将关键信息注入系统提示或上下文

### 4.2 知识检索触发

- 主协调者判断需要外部知识时，调用知识库检索
- 检索结果以指针形式注入上下文：`[KNOWLEDGE:{id}]`
- 详细内容从知识文件加载

### 4.3 学习触发

- 对话中用户说"记住这个" → 写入记忆
- 用户提供链接 → 触发链接自主学习流程
- 任务完成后主协调者总结 → 可选写入知识库

# 11 角色切换

> 状态：已定稿 | 最后更新：2026-01-15 | 对应决策：10, 11, 12, 20, 26（权威见 `design/03-权限模型.md` §6、`design/23-多模态与扩展.md` §3、`modules/07-主协调者.md` §5.4）

## 角色定义

角色 = 顶层容器，包含：

- 工具集（固定绑定，决策 7）
- 权限范围（max_permission）
- 知识域
- 专属子 Agent
- 系统提示词
- 记忆空间（决策 11）

**人设与模型解耦**：角色的系统提示词（人设）随角色配置走，**不写入模型**；更换/升级底层模型、改模型路径都不会改变角色人设（模型纯净原则，见 `ops/12-模型部署.md`）。

**模型档位解耦（B+D）**：`model_preference` 只声明**档位**（`light` / `heavy` / `cloud`），具体模型由环境映射表决定（见 `ops/12-模型部署.md` §模型池与档位）——换机 / 升级只改映射一处，角色与人设不动；最小模型集先跑通，按别扭点数据驱动特化。

## 角色 YAML Schema

字段与 `03-权限模型.md` / `23-多模态与扩展.md` 保持一致：

```yaml
# roles/extensions/resource_manager.yaml
id: resource_manager
name: 资源管理助手
version: 1
description: 资源分类与下载管理

# 工具集（固定绑定，决策 7）
allowed_tools:
  - read_file
  - grep
  - find_api
  - download_manager

# 权限上限（决策 26）
max_permission: L2

# 知识域（决策 12）
knowledge_domains:
  - resource
  - audio_search
shared_read: true   # 可读 memory/shared/ 与 knowledge/shared/

# 专属子 Agent（复用通用 + 追加专用）
sub_agents:
  - resource_classifier   # 追加专用
  - analyzer              # 复用通用
  - tester                # 复用通用

# 模型偏好（决策 1）
model_preference: light   # 档位：light / heavy / cloud（具体模型由 ops/12 §模型池 映射决定，不写死）

# 系统提示词
prompt: |
  你是资源管理助手，专注于...
  工具集：find API、下载管理、音频搜索
  知识域：资源分类、淘淘功能逻辑
```

## 角色加载

启动时：

```
扫描 roles/builtin/（代码内，核心角色写死）
  + 扫描 roles/extensions/*.yaml（配置文件，加角色=加文件不改代码）
  → 合并注册表
  → 验证依赖（工具是否存在、模型是否可用）
  → 标记可用/不可用
```

## 切换机制

### 用户主动切换

用户说「切到通用模式」或「用开发角色」：

```
1. 当前角色上下文 → 序列化 → 存 cache/role_contexts/{role}.json（决策 10，见 07-主协调者.md §5.4）
2. 清理当前角色的子 Agent 实例
3. 加载新角色配置
4. 新角色上下文 → 反序列化（如有缓存）
5. 继续对话
```

### 路由层自动切换

路由层（3B）判定意图变化 → 建议切换 → 询问用户确认。

### 不确定时反问

路由层置信度低时 → 反问用户：「这个任务是开发相关还是通用问答？」

## 记忆隔离（决策 11）

| 角色 | 记忆目录 | 共享 |
|------|---------|------|
| 开发 | memory/dev/ | 读 shared/ |
| 通用 | memory/general/ | 读 shared/ |
| 资源 | memory/resource/ | 读 shared/ |

角色之间不互相读写记忆；`memory/shared/` 所有角色可读、不可改（需更新由主协调者代理）。

## 公共知识（决策 12）

`knowledge/shared/` 所有角色可读，但不可改（防止角色间污染）。

公共知识示例：

```json
{
  "id": "user_preference_naming",
  "title": "用户命名偏好",
  "content": {
    "summary": "用户偏好中文注释，变量名用驼峰，函数名用动词开头"
  },
  "source": "manual"
}
```

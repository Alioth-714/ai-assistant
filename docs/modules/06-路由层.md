# 06 - 路由层

> 状态：已定稿 | 最后更新：2026-01-15 | 关联：02-架构设计.md、03-权限模型.md、04-数据边界.md、07-主协调者.md

## 一、概述

路由层（Layer 0）是 ai-assistant 四层架构的**入口层**，负责接收用户输入、进行意图识别与分类，并将请求分发到合适的角色层（Layer 1）或主协调者（Layer 2）。

**核心职责**：
- 意图识别：判断用户输入类型（问答、任务执行、角色切换、配置修改等）
- 轻量分类：将请求路由到对应角色或处理通道
- 请求预处理：截断超长输入、标记多模态内容
- 负载保护：Token 硬上限 4K，超限时截断早期内容

**设计决策**：使用 **3B 模型**（qwen25-3b）处理路由逻辑，保证低延迟（< 500ms）和低显存占用（~2.5GB）。

## 二、职责边界

| 职责 | 说明 | 不负责 |
|------|------|--------|
| 意图识别 | 分类用户输入为预定义意图类别 | 不执行任务、不调用工具 |
| 角色路由 | 根据意图和当前上下文选择角色 | 不加载角色配置（交给 Layer 1） |
| 请求分发 | 将结构化请求传递给主协调者 | 不拆解任务（交给 Layer 2） |
| 输入预处理 | Token 计数、截断、多模态标记 | 不生成最终回复 |
| 快速拒绝 | 明显违规/超出能力范围的请求直接拒绝 | 不提供详细解释 |

## 三、意图分类

### 3.1 意图类别

| 意图 | 说明 | 路由目标 |
|------|------|---------|
| `chat` | 闲聊、简单问答 | 当前角色直接处理 |
| `task` | 明确任务（写代码、重构、搜索等） | 主协调者（Layer 2） |
| `role_switch` | 切换角色（`/role` 命令或自然语言） | 角色层（Layer 1） |
| `config` | 修改配置、查看设置 | 主协调者（工具调用） |
| `knowledge` | 添加/查询知识库 | 主协调者（知识工具） |
| `system` | 系统命令（/clear、/export、/debug） | 直接处理 |
| `multimodal` | 包含图片、文件等 | 多模态网关（见 `23-多模态与扩展.md`） |
| `unknown` | 无法分类 | 主协调者（尝试理解） |

### 3.3 路由 Prompt 模板
text
你是一个路由分类器。根据用户输入，输出意图类别和置信度。
意图类别：chat, task, role_switch, config, knowledge, system, multimodal, unknown
输出格式（JSON）：

## 四、Token 管理

### 4.1 硬上限

| 参数 | 值 | 说明 |
|------|------|------|
| 输入 Token 上限 | 4K | 超出部分截断 |
| 输出 Token 上限 | 256 | 路由只需输出简短 JSON |
| 上下文窗口 | 4K | 含系统提示 |

### 4.2 超限处理
Token 计数 > 4K
│
▼
保留：
├─ 系统提示（~200 tokens）
├─ 最近 2K tokens 的对话历史
└─ 当前输入（截断到 1.5K）
│
▼
丢弃早期对话轮次
纯文本
### 4.3 快速 Token 估算

- 使用近似计数（1 token ≈ 4 字符，中文 1 字 ≈ 1.5 token）
- 不调用 tokenizer（减少延迟）
- 精确计数在超限时由主协调者执行

## 六、性能要求

| 指标 | 目标 | 说明 |
|------|------|------|
| 路由延迟 | < 500ms | 含 3B 模型推理 |
| 显存占用 | ~2.5GB | Q4_K_M 量化 |
| 并发 | 单实例 | 路由是串行入口，不并发 |
| 可用性 | 常驻 VRAM | 不释放，保证低延迟 |

## 七、错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 3B 模型未加载 | 尝试加载，失败则返回 `unknown` 让主协调者处理 |
| 模型推理超时 | 2s 超时，返回 `unknown` |
| 输出格式错误 | JSON 解析失败 → 返回 `unknown` |
| Token 超限 | 截断后重试一次，仍超限 → 返回 `unknown` |
| 置信度过低 | < 0.5 → 返回 `unknown` |

所有错误记录日志，不中断主流程。

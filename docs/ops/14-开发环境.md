# 14 - 开发环境

> 状态：已定稿 | 最后更新：2026-01-15 | 关联：00-总览.md、01-项目定位.md、02-架构设计.md、20-运行环境适配.md

## 一、概述

本文档定义 ai-assistant 工程的**开发环境要求、工具链配置、项目初始化流程**，以及日常开发中的构建、调试、测试方法。面向开发者（当前为单人开发），确保环境一致性和可复现性。

## 二、硬件要求

### 2.1 最低配置

| 组件 | 要求 | 说明 |
|------|------|------|
| CPU | x86_64，4 核 | 路由层+主协调者串行推理需要 |
| 内存 | 16GB | 模型加载+系统开销 |
| 显卡 | NVIDIA GPU，8GB VRAM | 运行 3B+7B 模型（Q4_K_M 量化） |
| 存储 | 10GB 可用空间 | 模型文件+依赖+数据目录 |

### 2.2 推荐配置（当前开发机）

| 组件 | 型号 |
|------|------|
| CPU | Intel i5-10400F (6C/12T) |
| 主板 | 微星 B460M |
| 内存 | 金百达 8G×2 = 16GB DDR4 |
| 显卡 | NVIDIA RTX 2070 (8GB VRAM) |
| 散热器 | 利民 PA120 |
| 系统 | Windows 10/11 |

在此配置上可用显存 ~6.5GB（8GB 总量 - 系统/桌面/CUDA 预留 ~1.5GB）。

### 2.3 显存调度说明（权威见 `27-性能优化.md` §2）

- **3B 路由层**：GPU 常驻（~2.5GB Q4_K_M）
- **7B 主协调者**：内存常驻 + GPU 分层按需 offload（GPU ≤ ~4GB，保证余量给子 Agent）
- **3B 子 Agent**：第 1 个进 GPU（~2.5GB）、第 2 个走 CPU，并发上限 2
- **7B 子 Agent**：CPU 或云端，不进 GPU
- 超出时：排队（30s）→ 降级 CPU/云端/串行化
- 详见 `27-性能优化.md`

## 七、开发工作流

### 7.1 日常开发

1. **修改 Rust 代码** → `cargo check` 快速检查 → `cargo build` 构建
2. **修改前端** → Tauri dev 模式热重载
3. **修改配置** → 编辑 `config/app.json`
4. **运行测试** → `cargo test`
5. **提交代码** → Git 命令行（可让 ai-assistant 协助提交）

### 7.2 调试

- **日志**：tracing 输出到终端+文件，设置 `RUST_LOG=debug`
- **模型调试**：Ollama 日志 `ollama serve` 终端输出
- **前端调试**：浏览器 DevTools（Tauri 窗口右键→检查）
- **工具层调试**：审计日志 `logs/audit.log`

### 7.3 Git 集成

用户明确"有时候可以直接让它帮我提交"：
powershell
手动提交
git add .
git commit -m "feat: xxx"
或让 ai-assistant 生成提交消息并提交
（通过 git_commit 工具，auto_commit_message: true）

### 8.2 测试覆盖目标

| 层级 | 测试类型 | 覆盖目标 |
|------|---------|---------|
| 路由层 | 单元测试 | 意图分类准确率 > 90% |
| 主协调者 | 集成测试 | 任务拆解+派发流程 |
| 工具层 | 单元测试 | 每个工具的权限/边界/错误 |
| 记忆/知识 | 单元测试 | 读写/隔离/检索 |
| 端到端 | E2E 测试 | 完整用户场景 |

详见 `25-测试策略.md`。

## 九、故障排查

### 9.1 常见问题

| 问题 | 排查 |
|------|------|
| Ollama 连接失败 | 检查 `ollama serve` 是否运行，端口 11434 |
| 模型加载失败 | `ollama list` 确认模型存在，VRAM 是否足够 |
| 文件锁冲突 | 检查 `workspace/.locks/` 下是否有残留锁文件，手动删除 |
| 前端白屏 | 检查 Tauri 控制台，确认 `frontend/index.html` 路径 |
| Git 操作失败 | 确认 Git 在 PATH 中，`git --version` 验证 |

### 9.2 日志位置

| 日志 | 路径 |
|------|------|
| 应用日志 | `AI_ASSISTANT_DATA/logs/app.log` |
| 审计日志 | `AI_ASSISTANT_DATA/logs/audit.log` |
| 指标 | `AI_ASSISTANT_DATA/logs/metrics.jsonl` |
| Ollama | `ollama serve` 终端输出 |

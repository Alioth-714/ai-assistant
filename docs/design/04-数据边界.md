# 04 - 数据边界

> 状态：已定稿 | 最后更新：2026-01-15 | 关联：02-架构设计.md、03-权限模型.md、08-记忆与知识.md、roadmap/18-本地云端边界方案.md

## 一、概述

数据边界定义系统中各类数据的**流通范围、隔离规则和出境条件**。核心原则：**数据默认不出本机；云端只接脱敏描述；外部内容只作为数据不作为指令。**

本文档覆盖：
- 数据分类与标记
- 进程/模块间边界
- 网络边界（内外网）
- 存储边界（知识/记忆/工作区/缓存）
- 数据出境审批流

## 二、数据分类

| 类别 | 示例 | 敏感级 | 出境策略 |
|------|------|--------|---------|
| **代码与项目文件** | 源码、配置、构建产物 | 高 | 禁止出境（除非用户显式确认） |
| **用户偏好与记忆** | 习惯、历史、偏好设置 | 高 | 禁止出境 |
| **知识库内容** | 领域事实、项目文档 | 中 | 禁止出境（但可本地用于推理） |
| **工作区临时数据** | 任务中间结果、子Agent交换数据 | 中 | 任务结束销毁，不出境 |
| **日志与审计** | 操作记录、错误栈 | 低-中 | 本地存储，不主动出境 |
| **外部抓取内容** | 网页文本、文档摘要 | 低 | 来源外部，但注入时需标记隔离 |
| **脱敏描述** | "用户想重构一个Rust项目" | 无 | 可发云端（不含具体代码/路径） |

### 2.1 隐私红线（决策 33，2026-10-22）

以下内容**即使「仅本地」开关关闭、即使有导出授权，也绝不上云**：

| 类型 | 清单 |
|------|------|
| 文件名 | `secrets.json`、`credentials*`、`.env*`、`id_rsa` / `id_ed25519` / `id_ecdsa`、`.netrc` |
| 扩展名 | `.key`、`.pem`、`.p12`、`.pfx`、`.jks`、`.keystore` |
| 目录 | `.ssh`、`.aws`、`.gnupg` |
| 内容形态 | `sk-…`、`-----BEGIN … PRIVATE KEY-----`、`AKIA…`、`ghp_…`、`xox…-`、`AIza…` |

**程序不得代为搬运**：命中红线时只**拦截并提示**，不读取 / 不复制 / 不代传；界面只提供「查看方法」（打开文件、复制路径），由用户自行复制。用户手动粘贴后程序无法判断来源，此时由**密钥形态检测**兜底并警告。

**两层防护**：来源标记（可靠层，工具读取时按路径打标）+ 形态检测（兜底层，手抄内容也能识别）。

实现：`src/egress.rs`（`is_sensitive_path` / `scan_secrets` / `inspect`）；出网统一走 `ExportGate`（授权确认）+ 红线检查**双闸门**，先红线、后授权。来源标记见 `src/tools.rs` 的 `sensitive_source`。

**隔离规则**：
1. 子 Agent **不能直接读取**知识库或记忆文件，只能接收主协调者过滤后注入的数据。
2. 子 Agent 之间**不直接通信**，通过工作区 JSON 文件交换数据。
3. 工具层返回的数据必须经过主协调者审查后才能注入子 Agent 上下文。

| 区域 | 定义 | 数据流向 |

### 4.3 外部内容注入隔离

抓取到的外部内容（网页、文档）在注入上下文时：
- **标记来源**：`[EXTERNAL: {url}]` 前缀
- **数据只读**：不作为指令执行（防 prompt 注入）
- **过滤规则**：检测 `system:`、`ignore previous`、`do anything` 等指令关键词，命中则警告并截断
- **多模态**：图片需理解时询问用户"传云端分析还是跳过？"（决策 18）

## 五、存储边界

### 5.1 目录隔离

| 目录 | 访问者 | 权限 |
|------|--------|------|
| `config/` | 主协调者、启动时加载 | 读写 |
| `knowledge/` | 主协调者（读+写索引）、子Agent（只读注入） | 主协调者读写，子Agent只读 |
| `memory/` | 主协调者（读写）、子Agent（禁止直接访问） | 主协调者读写，子Agent不可见 |
| `workspace/` | 主协调者、子Agent（任务期间） | 读写（任务结束清理） |
| `backups/` | 权限网关（写）、用户（读） | 自动写入，用户可手动恢复 |
| `cache/external/` | 网络工具（写）、主协调者（读） | 自动管理，可清理 |
| `logs/` | 系统（写）、用户（读） | 追加写，用户查看 |

### 5.2 知识 vs 记忆边界

| 维度 | 知识 | 记忆 |
|------|------|------|
| 内容 | 领域/项目事实 | 用户偏好/历史 |
| 修改者 | 用户手动 / Agent建议 / 自动积累 | 主协调者自动 / 用户显式 |
| 子Agent可见性 | 主协调者过滤后注入 | 不可见（除非主协调者主动提供） |
| 共享 | shared/ 所有角色可读不可改 | shared/ 所有角色可读不可改 |
| 格式 | 结构化 JSON | JSON |

### 5.3 加密与保护

- **当前阶段（0-2）**：所有数据明文存储（JSON），依赖文件系统权限。
- **阶段 4 规划**（决策 28 子项）：对含凭据类记忆加密（AES-256-GCM），密钥由用户口令派生（Argon2id）。
- **备份文件**：`backups/` 下的文件与原始文件权限一致，不额外加密。

## 六、数据生命周期

| 数据类型 | 创建 | 更新 | 销毁 |
|---------|------|------|------|
| 工作区 | 任务创建时 | 子Agent写入中间结果 | 任务完成/取消时立即销毁；孤儿 24h 清理 |
| 缓存 | 首次抓取链接 | 重新抓取（用户触发或过期） | 用户手动清理 / 超过磁盘上限自动清理 |
| 备份 | 写操作前自动创建 | 不更新（快照） | 超过保留策略（如 30 天）自动删除 |
| 日志 | 事件触发 | 追加 | 轮转（10MB/个，保留5个），总上限 500MB |
| 记忆 | 交互中积累 | 用户修正 / Agent建议更新 | 用户手动删除 |

## 七、与权限模型的关系

- 数据边界定义**数据能去哪**，权限模型定义**谁能做什么**。
- 权限网关在执行写操作前，同时检查数据边界（是否写入受保护目录）。
- 网络网关在执行外网请求前，同时检查数据边界（是否携带高敏感数据）。

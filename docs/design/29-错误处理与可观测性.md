# 29 - 错误处理与可观测性

> 状态：已定稿 | 最后更新：2026-01-15 | 关联：02-架构设计.md、05-失败处理.md、22-安全模型.md、25-测试策略.md、27-性能优化.md、28-数据持久化与存储.md

## 一、概述

ai-assistant 作为本地多 Agent 协作系统，涉及模型推理、工具调用、文件操作、网络通信等多个故障面。本文档定义**错误处理策略、日志体系、指标采集和用户反馈机制**，确保系统在异常情况下**可诊断、可恢复、可审计**。

**核心原则**：
- **库代码用 `thiserror` 定义具名错误类型**，顶层用 `anyhow` 做兜底（决策 25，用户已接受）
- **失败处理流程**：重试 → 检查原因 → 回滚已改 → 报告用户（决策 3）
- **不吞错误**：所有错误必须被记录、分类、上报（至少到日志）
- **用户可见错误**：清晰、可操作，不暴露内部实现细节
- **可观测性三支柱**：日志（Logging）、指标（Metrics）、追踪（Tracing）

## 二、错误处理策略

### 2.1 分层错误处理

| 层级 | 策略 | 工具 |
|------|------|------|
| 库代码（tools、gateway、workspace 等） | 定义具名错误类型，携带上下文 | `thiserror` |
| 应用顶层（main、coordinator 调度） | 兜底捕获，转换为用户友好消息 | `anyhow` + `thiserror` |
| 前端 | 显示用户友好消息，记录错误 ID | 弹窗/内联提示 |

## 三、失败处理流程（决策 3）

### 3.1 标准流程

│
▼

│ 1. 重试 │ ← 按类型重试（见 05 §6.1）

│ 仍失败
▼

│ 4. 报告用户 │ ← 清晰描述 + 建议操作

### 3.2 重试策略

| 错误类型 | 重试次数 | 退避策略 |
|---------|---------|---------|
| 网络超时 | 3 | 指数退避：1s, 2s, 4s |
| Ollama 推理超时 | 2 | 固定 2s |
| 文件锁冲突 | 5 | 固定 500ms |
| 配置解析错误 | 0 | 不重试，直接报告 |
| 权限拒绝 | 0 | 不重试，直接报告 |

### 3.3 回滚触发条件

- 写文件操作失败（部分写入）
- 多文件操作（如重构）中某个文件失败
- 工具调用返回不可恢复错误
- 用户主动取消操作

### 3.4 用户报告格式
❌ 操作失败：重构 src/main.rs
原因：文件写入失败（磁盘空间不足）
已执行：读取了 3 个文件，修改了 1 个文件（已自动回滚）
建议：释放磁盘空间后重试，或联系支持
错误 ID：ERR-20260115-001

### 4.2 日志级别

| 级别 | 用途 | 示例 |
|------|------|------|
| `ERROR` | 不可恢复错误、操作失败 | 模型推理失败、写文件崩溃 |
| `WARN` | 可恢复的异常、降级 | 显存不足降级 CPU、备份失败 |
| `INFO` | 关键流程节点 | 任务创建、角色切换、模型加载 |
| `DEBUG` | 详细诊断信息 | 工具调用参数、权限检查结果 |
| `TRACE` | 最细粒度追踪 | 每个 token 生成、每次文件读取 |

## 六、用户可见错误

### 6.1 错误展示原则

- **不暴露内部路径、堆栈、UUID**（除非用户开启调试模式）
- **提供错误 ID**：`ERR-{日期}-{序号}`，用户可提供给开发者排查
- **给出建议操作**：重试、修改配置、释放资源等
- **区分严重级别**：提示（info）、警告（warn）、错误（error）、致命（fatal）

### 6.2 前端错误展示

| 级别 | 样式 | 行为 |
|------|------|------|
| 提示 | 蓝色内联消息 | 自动消失（3s） |
| 警告 | 黄色内联消息 | 需用户关闭 |
| 错误 | 红色卡片 | 阻塞操作，显示错误 ID 和建议 |
| 致命 | 全屏遮罩 | 要求重启或联系支持 |

### 6.3 错误 ID 生成
ERR-{YYYYMMDD}-{4位序号}
纯文本
- 每次生成错误时递增
- 对应条目写入 `logs/app.log` 和 `logs/audit.log`
- 用户可用错误 ID 在日志中定位完整上下文

## 七、调试与诊断

### 7.1 调试模式

- 环境变量：`AI_ASSISTANT_DEBUG=1`
- 效果：
  - 日志级别设为 `DEBUG`
  - 前端显示调试面板（显存、token、Agent 状态）
  - 错误显示完整堆栈
  - 审计日志额外记录输入/输出摘要

### 7.2 诊断命令

| 命令 | 说明 |
|------|------|
| `/debug info` | 显示系统信息（硬件、模型、配置） |

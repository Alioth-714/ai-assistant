# 24 - 前端交互设计

> 状态：已定稿 | 最后更新：2026-01-15 | 关联：02-架构设计.md、03-权限模型.md、20-运行环境适配.md、23-多模态与扩展.md

## 一、概述

前端采用 **纯 HTML + CSS + JS** 构建，通过 **Tauri v1** 封装为桌面应用（决策 20）。不使用任何前端框架（React/Vue 等），以保持轻量、可维护，并方便用户以"纯文字版本"进行指导和修改（用户倾向）。

**核心目标**：
- 提供清晰的对话交互界面，支持流式输出
- 权限请求、任务进度、系统状态以非侵入方式展示
- 用户可轻松查看/编辑配置、管理知识库和记忆
- 所有交互可审计，敏感信息不暴露在前端

**设计原则**：
- **默认静默，可展开**（决策 5）：轻量级事件不打扰用户，需要时用户可展开详情
- **文字优先**：界面以文本信息为主，减少图形装饰
- **本地优先**：所有数据存储在本地，前端不直接访问网络（网络请求由后端工具层代理）

## 二、技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| UI 渲染 | 纯 HTML + CSS + JS | 无框架依赖，直接操作 DOM |
| 桌面封装 | Tauri v1 | 后端 Rust，前端通过 `invoke` 调用命令 |
| WebView | Windows: WebView2 | 需系统安装 |
| 样式 | CSS Variables + 简单布局 | 支持明暗主题切换 |
| 通信 | Tauri `invoke` + `event` | 前端→后端：invoke；后端→前端：事件监听 |
| 构建 | 无构建步骤（直接复制文件） | 开发时直接编辑 HTML/JS，刷新即可 |

### 3.1 侧边栏

- **角色选择**：显示当前角色，点击切换（弹出角色列表）
- **任务列表**：显示当前/最近任务，点击展开任务详情（子 Agent 状态、工作区文件）
- **知识库/记忆**：快速搜索入口，点击打开知识管理页面
- **设置**：配置编辑、模型管理、日志查看入口

### 3.2 主区域

- **对话历史**：消息列表，支持代码高亮、表格、折叠块
- **任务进度**（可折叠）：默认显示简要进度，点击展开查看子 Agent 详情
- **输入区**：多行文本输入，支持 `/命令`（如 `/role`, `/clear`, `/export`）

### 3.3 状态栏

- 显示系统状态：GPU 显存、运行中的 Agent 数、待确认权限数
- 权限确认中时闪烁提示

## 四、对话交互

### 4.1 消息展示

| 消息类型 | 样式 | 说明 |
|---------|------|------|
| 用户消息 | 右对齐，蓝色背景 | 纯文本，支持代码块 |
| 助手消息 | 左对齐，灰色背景 | 支持 Markdown 渲染 |
| 系统通知 | 居中，浅黄色背景 | 任务完成、权限提示等 |
| 错误/警告 | 居中，红色/橙色背景 | 失败、回滚提示 |
| 任务进度 | 内嵌卡片 | 可折叠，显示子 Agent 状态 |

**代码块**：语法高亮，提供"复制"、"应用"按钮（点击"应用"触发文件写入，需 L2 确认）。

### 4.2 流式输出

- 主协调者回复采用流式显示（逐字/逐句追加）
- 使用 `ReadableStream` 或 Tauri 事件推送
- 流式过程中显示"停止"按钮，点击可中断生成

### 4.3 多模态输入

- 图片粘贴/拖拽：显示缩略图，提示"传云端分析还是跳过？"（决策 18）
- 文件拖拽：识别为文件路径，询问是否读取内容

### 4.4 用户感知（决策 5）

- **默认静默**：子 Agent 执行、工具调用等后台事件不弹窗，只在状态栏显示计数
- **可展开**：用户点击状态栏或任务列表，展开查看详情
- **关键事件**：需要用户确认的操作（L2/L3）弹出模态对话框，阻塞对话直到用户响应

- **查看详情**：展开完整 diff 和上下文

## 六、角色与任务管理

### 6.1 角色切换

- 侧边栏点击角色 → 弹出角色列表（内置 + 自定义）
- 选择后，主协调者加载新角色配置（YAML），上下文存角色缓存池
- 切换后对话历史保留（可配置是否清空）

### 6.2 任务进度展示

- 任务卡片显示：任务 ID、描述、状态（进行中/完成/失败）、子 Agent 列表
- 子 Agent 状态：名称、执行工具、进度百分比
- 点击子 Agent 可查看工作区文件（只读）

### 6.3 任务控制

- 用户可取消进行中的任务（发送取消信号给主协调者）
- 可强制终止无响应的子 Agent

## 七、设置与配置

### 7.1 配置编辑

- 直接编辑 `config/app.json`（前端提供 JSON 编辑器，带语法高亮和验证）
- 修改后保存，提示重启生效（或热重载部分配置）

### 7.2 模型管理

- 显示已安装的 Ollama 模型列表
- 提供 `ollama pull` 命令执行入口（用户确认后）
- 模型切换：修改 `app.json` 中 `models.*` 字段

### 7.3 网络策略配置

- 域名白名单/黑名单编辑
- 开关：是否允许外部源、是否询问首次访问

### 7.4 知识库/记忆管理

- 知识库浏览器：按分类浏览、搜索、编辑 JSON
- 记忆查看器：显示当前角色记忆，可手动编辑/删除
- 导入/导出：从文件导入知识，导出为 JSON

## 八、日志与审计查看

- 日志页面：显示 `logs/` 下的日志文件，支持筛选级别（error/warn/info/debug）
- 审计日志：显示 `audit.log`，可按时间、事件类型筛选
- 备份管理：显示 `backups/` 目录，可手动恢复或删除

## 九、主题与可访问性

- 支持明暗主题（CSS Variables 切换）
- 字体大小可调
- 高对比度模式（可选）
- 键盘快捷键：发送（Ctrl+Enter）、换行（Shift+Enter）、切换角色（Ctrl+R）

### 10.2 事件监听

// 监听流式输出
listen('stream_chunk', (event) => {

// 监听权限请求

});
// 监听任务进度

## 十一、安全约束

- 前端不存储敏感信息（如 API Key），只从后端读取脱敏状态
- 所有用户输入经过后端验证，前端不做权限决策
- 日志和审计日志只读展示，不可从前端删除
- 配置编辑时，敏感字段（如 `secrets`）显示为 `****`，需用户显式解锁

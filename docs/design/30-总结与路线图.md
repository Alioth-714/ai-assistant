# 30 - 总结与路线图

> 状态：已定稿 | 最后更新：2026-01-15 | 关联：00-总览.md、01-项目定位.md、02-架构设计.md、roadmap/15-开发路线.md、roadmap/18-本地云端边界方案.md

## 一、概述

本文档是 ai-assistant 工程 **33 项架构决策** 的最终总结，涵盖从项目定位到部署运维的全部设计结论。同时定义 **五阶段开发路线图（阶段 0-4）** 的范围、交付物与退出标准，作为团队（当前为单人开发）推进实施的纲领。

**工程标识**：
- 工程名：`ai-assistant`（GitHub 全小写连字符，本地目录可 `AIAssistant`）
- 内部中文名：小明同学
- 前端：纯 HTML + CSS + JS（Tauri v1 封装）
- 后端：Rust（ollama-rs、tracing、thiserror、anyhow）
- 模型：Ollama 本地推理（qwen25-3b / qwen25-7b）

### 2.2 关键决策速查表（33 项）

| # | 决策 | 核心结论 |
|---|------|---------|
| 1 | 混合模型 | 轻活 3B / 重活 7B / 外部走云端 |
| 2 | 子 Agent 共享数据 | 结构化 JSON 工作区，任务建/完成销毁，孤儿 24h 清理 |
| 3 | 失败处理 | 重试→检查原因→回滚已改→报告用户 |
| 4 | 子 Agent 嵌套 | 禁止 |
| 5 | 用户感知 | 默认静默可展开 |
| 6 | 回滚 | 文件级备份（写前备份） |
| 7 | 工具集 | 固定绑定 Agent 类型 |
| 8 | Token 硬上限 | 3B=4K / 7B=8K |
| 9 | 主协调者上下文 | 外移指针+满时摘要压缩 |
| 10 | 角色切换 | 常驻复用主协调者实例+上下文存角色缓存池 |
| 11 | 记忆分层 | 独立+公共两层（shared 所有角色可读不可改） |
| 12 | 知识库三层 | knowledge/{shared,general,{custom_role}} |
| 13 | 知识文件格式 | 结构化 JSON |
| 14 | 检索策略 | 先关键词后向量（阶段 3+ 升级） |
| 15 | 知识维护 | 混合（manual/agent/hybrid） |
| 16 | 链接自主学习 | 抓取总结成知识库，外网需询问且不能太频繁 |
| 17 | 外网访问 | B 平衡策略（docs.*/wiki.*/github.com 默认允许+可配置，其他首次询问） |
| 18 | 图片多模态 | 询问用户"传云端分析还是跳过？" |
| 19 | 链接缓存 | 独立目录 `cache/external/` |
| 20 | 前端技术 | 纯 HTML+CSS+JS（Tauri v1） |
| 21 | 配置格式 | JSON（缩进 2 空格+字段排序+注释用 `_comment`） |
| 22 | Ollama 通信 | ollama-rs crate |
| 23 | Git 集成 | 命令行调用（用户明确"有时候可以直接让它帮我提交"） |
| 24 | 日志 | tracing crate（可配置输出路径到文件+终端） |
| 25 | 错误处理 | 混合（库代码 thiserror / 顶层 anyhow，用户已接受） |
| 26 | 权限模型 | L0-L3 四级，与网络策略正交 |
| 27 | 数据边界 | 路径遍历防护、敏感数据不出境 |
| 28 | 安全模型 | Prompt 注入防护、写操作互斥、敏感记忆加密（阶段4） |
| 29 | 性能优化 | 显存调度、并发上限、异步备份、上下文分段 |
| 30 | 测试策略 | 单元/集成/E2E/性能/安全分层覆盖 |
| 31 | Planner 子层 | 计划先行+单步决策；第一版模板状态机(P1)，开放式云端拆plan；单步决策用大脑 qwen25-7b（唯一档位） |
| 32 | Tool Guard 子层 | 前置校验+写后自检+循环≥3拦截→修正重试1次→报告用户；纯代码零模型 |
| 33 | 能力分层与云端对接 | 按认知复杂度分档(local/localFirst/cloud)；仅本地开关默认开；profile small/large；隐私红线不随开关变化；会话预算上限 |

## 三、开发路线图

详细版本见 `roadmap/15-开发路线.md`，此处为摘要。

### 阶段 0：复用验证期

**目标**：不写自研代码，用 Cline + Ollama + `agent.md` 跑通「角色 + 工具 + 记忆」工作方式，记别扭点。

| 范围 | 交付物 | 退出标准 |
|------|--------|---------|
| Cline 配置 Ollama 并注入 agent.md | 角色行为符合预期 | 多轮对话表现稳定 |
| 验证工具调用/记忆读写 | 别扭点清单（≥10 条） | 作为阶段 1 需求输入 |

### 阶段 1：核心骨架（MVP）

**目标**：跑通四层架构的最小闭环，验证本地模型推理+工具调用。

| 范围 | 交付物 | 退出标准 |
|------|--------|---------|
| 路由层（3B） | 意图识别、分发逻辑 | 能正确分类用户输入并路由 |
| 主协调者（7B） | 任务拆解、子 Agent 派发 | 能拆解简单任务并派发 |
| 子 Agent（3B） | 单文件读写、grep | 能完成"读文件→修改→写回" |
| 工具层 | read_file/write_file/grep | 工具调用成功，权限网关生效 |
| 前端 | 基础对话界面（Tauri） | 能发送消息、显示流式输出 |
| 数据层 | 工作区 JSON、配置 JSON | 目录结构创建，配置可读取 |

### 阶段 2：协作与记忆

**目标**：多 Agent 协作流畅化，记忆/知识库可用，失败处理完善。

| 范围 | 交付物 | 退出标准 |
|------|--------|---------|
| 多 Agent 协作 | 广播/认领、工作区共享 | 2 个子 Agent 并发不冲突 |
| 记忆系统 | 分层记忆读写 | 角色切换记忆隔离 |
| 知识库 | 三层结构、关键词检索 | 手动添加知识，检索可用 |
| 失败处理 | 重试、回滚、报告 | 诱导失败后自动回滚成功 |
| 权限网关 | L0-L3 拦截、确认弹窗 | L2 操作弹窗确认 |
| 前端增强 | 任务进度、权限弹窗、设置页 | 用户可查看任务状态 |

### 阶段 3：扩展与优化

**目标**：扩展机制、性能优化、网络能力、测试覆盖。

| 范围 | 交付物 | 退出标准 |
|------|--------|---------|
| 工具扩展 | 新增工具注册机制 | 新增工具无需修改核心代码 |
| 角色扩展 | 自定义角色 YAML | 用户可创建并切换自定义角色 |
| 知识检索升级 | 向量检索（阶段 3+） | 语义搜索可用 |
| 网络能力 | 链接抓取、域名策略 | 外网访问受控，缓存生效 |
| 性能优化 | 显存调度、并发上限、缓存 | 目标硬件上流畅运行 |
| 测试覆盖 | 集成测试、E2E 测试 | 核心流程测试通过率 100% |

### 阶段 4：安全与生态

**目标**：安全加固、加密、插件生态、正式发布。

| 范围 | 交付物 | 退出标准 |
|------|--------|---------|
| 安全加固 | Prompt 注入防护、加密存储 | 渗透测试无高危漏洞 |
| 敏感记忆加密 | AES-256-GCM | 加密字段不可明文读取 |
| 插件生态 | Tauri 插件机制 | 第三方插件可加载 |
| 自动更新 | 增量更新、回滚 | 更新失败可自动回滚 |
| 文档完善 | 用户手册、开发指南 | 用户可自助部署和使用 |
| 正式发布 | GitHub Release、安装包签名 | 可对外分发 |

## 四、退出标准（通用）

每个阶段必须满足：

1. **功能完整**：该阶段定义的所有交付物已实现并通过测试
2. **文档同步**：对应 `docs/` 文件已更新至最新状态
3. **性能达标**：满足 `27-性能优化.md` 中定义的指标
4. **安全合规**：通过 `22-安全模型.md` 和 `25-测试策略.md` 中的安全测试
5. **用户验收**：用户（当前为开发者本人）在目标硬件上验证通过

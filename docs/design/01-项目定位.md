# 01 - 项目定位

> 状态：已定稿 | 最后更新：2026-01-15 | 关联：00-总览.md、02-架构设计.md

## 一、背景与动机

用户日常开发中需要频繁切换工具、查阅文档、执行重复操作。现有 AI 编码助手（如 GitHub Copilot）依赖云端、缺乏本地上下文感知、无法自主执行多步骤任务。我们希望构建一个**完全运行在本地**的 AI 助手，能够：

- 理解项目结构、用户偏好、历史对话
- 自主拆解任务并调度多个专业子 Agent 并行执行
- 安全地处理文件读写、命令执行、网络抓取
- 不依赖云端即可完成大多数开发辅助工作

## 二、项目愿景

**小明同学** —— 一个本地优先、隐私安全、可扩展的个人 AI 助手底座。一个底座承载多个角色（开发/通用/垂直领域），每个角色内含主协调者+专业子 Agent 群协作。

最终形态：
- 用户用自然语言描述需求
- 本地 8B 模型理解意图、拆解任务、调度子 Agent
- 子 Agent 各自独立执行（读代码、写文件、跑命令、查文档）
- 结果汇总回主协调者，格式化输出给用户
- 全程数据不出本机，敏感操作需用户确认

## 三、目标与范围

### 阶段 0-2（当前聚焦）

| 目标 | 说明 |
|------|------|
| 本地推理 | 仅用 Ollama 调用 qwen25-3b / qwen25-7b，不直加载 GGUF |
| 四层架构 | 路由(3B) → 角色配置 → 主协调者(8B) → 子Agent(3B/8B) |
| 多 Agent 协作 | 任务派发、认领、工作区共享、并发互斥 |
| 工具层 | 文件操作、grep、git CLI、网络抓取（受控） |
| 权限网关 | L0-L3 分级，写操作 L2 确认 |
| 记忆与知识 | 分层存储，JSON 格式，启动时加载索引 |
| 前端 | Tauri v1 + 纯 HTML/CSS/JS，轻量交互 |

### 阶段 3-4（规划中）

- 知识库向量检索
- 链接自主学习（抓取→总结→知识库）
- 云端兜底（脱敏后）
- 多模态（图片理解，询问用户）
- 敏感记忆加密

## 四、非目标（明确不做）

| 不做的事 | 原因 |
|---------|------|
| 替代 IDE | 定位是助手/搭档，不是编辑器 |
| 云端训练/微调 | 本地优先，数据不出本机 |
| 多用户/团队协作 | 个人助手，无多租户设计 |
| 实时语音交互 | 阶段 0-2 聚焦文本，语音后续评估 |
| 移动端支持 | 桌面端优先（Windows 为主） |
| 直加载 GGUF | 阶段 0-2 用 Ollama 管理模型生命周期 |

## 五、核心原则

1. **本地优先，隐私至上**：数据默认不出本机；云端仅接脱敏描述；用户可完全离线使用。
2. **安全第一**：写操作必须确认；外部内容不作为指令；文件锁防并发冲突。
3. **渐进增强**：从简单单轮对话起步，逐步增加多 Agent、知识库、云端能力。
4. **可解释性**：Agent 行为可追溯（日志、工作区、备份）；用户随时可审计。
5. **开发者友好**：配置用 JSON（人读友好）；角色定义用 YAML；前端纯 HTML/CSS/JS。
6. **资源感知**：根据硬件（i5-10400F/16GB/RTX2070 8GB）合理分配模型加载和并发。

## 六、关键术语

| 术语 | 含义 |
|------|------|
| 主协调者 | Layer 2，8B 模型，唯一与用户对话的实体，负责任务拆解和调度 |
| 子 Agent | Layer 3，执行具体任务的独立实例，返回结构化结果 |
| 路由层 | Layer 0，3B 模型，仅做意图分类（开发/通用/垂直） |
| 角色 | Layer 1，配置集合（工具集/权限/知识域/prompt），决定主协调者的行为边界 |
| 工作区 | `AI_ASSISTANT_DATA/workspace/{task_id}/`，任务期间的临时数据交换区 |
| 权限网关 | 拦截所有写操作和网络访问，按 L0-L3 分级控制 |
| 知识库 | 领域/项目事实，结构化 JSON，主协调者过滤后注入子 Agent |
| 记忆 | 用户偏好/历史，JSON，分层存储（独立+公共） |

## 七、与同类工具的差异

| 工具 | 差异点 |
|------|------|
| GitHub Copilot | 云端依赖、无本地上下文、无自主执行能力 |
| Cline | 单 Agent 架构，无多 Agent 协作，无角色切换 |
| AutoGPT | 无资源约束，无权限控制，不适合本地 8GB 显存 |
| 小明同学 | 本地优先、四层架构、多 Agent 协作、资源感知、权限网关 |

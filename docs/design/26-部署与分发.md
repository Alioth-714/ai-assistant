# 26 - 部署与分发

> 状态：已定稿 | 最后更新：2026-01-15 | 关联：20-运行环境适配.md、21-更新与回滚.md、24-前端交互设计.md、25-测试策略.md

## 一、概述

ai-assistant 是纯本地运行的桌面应用，无云端依赖（推理走本地 Ollama）。本文档定义应用的**打包、分发、安装、更新和卸载**流程。

**核心原则**：
- 用户可一键安装，也可便携运行（免安装）
- 安装过程透明，不静默修改系统设置
- 更新可回滚（见 `21-更新与回滚.md`）
- 卸载干净，不残留用户数据（除非用户选择保留）

## 二、分发形态

### 2.1 安装包（推荐）

| 平台 | 格式 | 工具 |
|------|------|------|
| Windows 10/11（首选） | MSI / NSIS (.exe) | Tauri `tauri build` → NSIS 安装程序 |
| Windows 7（阶段 2+） | 便携版 .zip（Tauri v1 + WebView2 Fixed Runtime） | 手工打包（这也是选 Tauri v1 的原因） |
| Linux | AppImage（主）/ .deb | Tauri `tauri build` → 对应格式 |
| macOS | 不在本期规划 | — |

**Windows 安装包特性**：
- 安装目录默认：`C:\Users\{user}\AppData\Local\ai-assistant\`
- 可选：安装到自定义路径
- 开始菜单快捷方式
- 可选：桌面快捷方式
- 可选：添加到 PATH（命令行 `ai-assistant` 可启动）
- 不修改注册表（除卸载信息外）
- 不安装系统服务（Ollama 由用户自行管理）

### 2.2 便携版（Portable）

- 单个目录，解压即可运行
- 数据目录默认在程序目录下 `data/`（可通过环境变量覆盖）
- 适合 U 盘携带、测试使用
- 不创建快捷方式或注册表项

### 2.3 源码分发

- GitHub 仓库（用户私人空间，英文名 `ai-assistant`）
- 用户可从源码构建：`cargo tauri build`
- 依赖：Rust 1.75+、Node.js（Tauri CLI）、Ollama

  - `Cargo.toml` → `version`

### 4.2 Ollama 检测与引导

安装完成后，若未检测到 Ollama：
1. 显示提示页面："需要安装 Ollama 以运行本地模型"
2. 提供下载链接（https://ollama.com/download）
3. 用户安装完成后，提示运行 `ollama pull qwen25-3b` 和 `ollama pull qwen25-7b`
4. 可一键复制命令到剪贴板

### 4.3 首次启动初始化

首次启动时（见 `20-运行环境适配.md` §5.3）：
1. 检测数据目录（默认 `AI_ASSISTANT_DATA`）
2. 创建目录结构（config/ knowledge/ memory/ workspace/ backups/ cache/ logs/）
3. 生成默认 `config/app.json`
4. 检测 Ollama 连接和模型可用性
5. 进入主界面

### 4.4 离线部署（阶段 3+）

完全离线环境（无外网）的部署方案：

- 安装包可附带 **Ollama 离线安装程序** + 必需模型文件（qwen25-3b / qwen25-7b 的 Ollama 格式）
- 离线包结构：`ai-assistant_离线包/` = 安装包 + `ollama-setup.exe` + `models/`（导入命令：`ollama import`）
- 离线模式下自动禁用外网功能（链接抓取、云端模型、自动更新检查）

## 五、更新机制

### 5.1 更新检测

| 方式 | 说明 |
|------|------|
| 手动检查 | 设置页面 → "检查更新"按钮 |
| 自动检查 | 启动时静默检查（可关闭），受网络策略约束 |
| 版本文件 | GitHub Release 中的 `latest.json`，包含版本号、下载链接、校验和 |

### 5.3 增量更新（阶段 3+）

- 对比文件差异，只下载变更文件
- 减少带宽消耗（模型文件不纳入增量，需单独管理）

## 七、数据迁移（重装/换机）

### 7.1 备份
powershell
备份全部用户数据
Compress-Archive -Path "$env:LOCALAPPDATA\ai-assistant\data" -DestinationPath "ai-assistant-data-backup.zip"
纯文本
### 7.2 恢复

1. 安装 ai-assistant（新机器或重装后）
2. 首次启动前解压备份到数据目录
3. 启动后自动检测 schema_version，触发迁移（如需要）

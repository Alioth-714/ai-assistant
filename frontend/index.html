                                主题
                                跟随系统或固定浅色 / 深色。
                            
    
                            
                        
    
                    
    

                    
    
                        
    
                            
    
                                Ollama 地址
                                修改后需重启应用生效。
                            
    
                            
                        
    
                        
    
                            
    
                                路由模型
                                轻量模型，用于角色判定。
                            
    
                            
                        
    
                        
    
                            
    
                                协调模型
                                主对话模型，用于最终回答。
                            
    
                            
                        
    
                        
    
                            
    
                                模型目录
                                只读展示，模型文件仍由 Ollama 管理。
                            
    
                            -
                        
    
                    
    

                    
    
                        
    
                            
    
                                角色
                                自定义角色会出现在输入框旁的角色滚轮中。
                            
    
                            
                        
    
                        
    
                        
    
                            
                            
                            
                            
                            
    
                                
                                
                            
    
                        
    
                    
    

                    
    
                        
    
                            
    
                                数据目录
                                会话、记忆、角色与日志都保存在这里。
                            
    
                            -
                        
    
                        
    
                            
    
                                日志目录
                                排查问题时可查看 app.log。
                            
    
                            -
                        
    
                        
    
                            
    
                                迁移数据目录
                                把当前数据复制到新目录并逐字节校验，写指针后重启生效；只迁移当前默认目录，不引入 fs/dialog 插件。
                            
    
                            
    
                                
                                
                            
    
                        
    
                        
    
                    
    

                    
    
                        
    
                            
    
                                默认对话模型
                                发送消息时优先使用本地模型或某个外部 Provider。
                            
    
                            
                        
    
                        
    
                            
    
                                云端模式
                                仅云端会关闭本地 3B 路由与工具，全部走外部模型。
                            
    
                            
                        
    
                        
    
                            
    
                                会话云端预算
                                token 上限，0 表示不限；超额自动降级为仅本地。
                            
    
                            
                        
    
                        
    
                            
    
                                能力档位
                                small = 3B+7B（复杂任务上云）；large = 14B+（本地承担更多）。
                            
    
                            
                        
    
                        
    
                            
    
                                出网记录
                                最近的云端发送 / 拦截（来源 audit.log）。
                            
    
                            
                        
    
                        
    
                        
    
                            
    
                                外部 Provider
                                OpenAI 兼容接口，Base URL 例如 https://api.deepseek.com/v1。
